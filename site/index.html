Set up your context brain

A folder of notes on your own computer that Claude reads and writes, so it understands your role, your colleagues and what you are working on without being told each time. This page installs it. About ten minutes, and no administrator rights.

Are you on a Mac or a Windows computer?

Installing on Mac.

Three steps

  1. Open Terminal. Press ⌘ and the space bar together, type Terminal, press Enter. A window with a text prompt opens. Everything below gets pasted in there.
  2. Paste this, all four lines at once, then press Enter. 
    cd ~/Downloads
curl -fLO https://sistergroup.github.io/install-brain/brain-macos.tar.gz
mkdir -p brain-installer && tar -xzf brain-macos.tar.gz -C brain-installer
cd brain-installer && ./install.sh

    This downloads the installer to your Downloads folder, unpacks it and runs it. Nothing is hidden: you can open that folder and read every file before or after.

  3. Answer four questions. Your name, your work email, your company, and where the folder should live. The recommended answer is offered for the last one, so pressing Enter is fine.

When it finishes it prints the remaining steps, which all happen inside the Claude app. The same instructions are saved in your new folder as START HERE.md.

If you would rather look first

Run it with --dry-run and it reports every decision it would make and changes nothing:

cd ~/Downloads/brain-installer && ./install.sh --dry-run

Or Download the installer and unpack it by double-clicking, if you prefer not to use commands to fetch it. You will still need Terminal for the last line.

If something goes wrong

It says permission denied

The execute permission did not survive the download. Fix it and run again:

chmod +x install.sh && ./install.sh
It says it could not download something

Your network is probably blocking it. The installer needs to reach sistergroup.github.io to fetch itself, and obsidian.md and claude.ai to install the two apps. Try again off the company VPN, or ask whoever set this up.

It already found a brain on my machine

Then it offers to use that one and add only what is missing. Nothing you have already written is changed or overwritten, and saying yes is safe.

I want to run it again

Safe. Every step checks first and skips what is already there. Notes, skills and your Obsidian settings are never overwritten.

Installing on Windows.

Three steps

  1. Open PowerShell. Press the Windows key, type PowerShell, press Enter. A window with a text prompt opens. Everything below gets pasted in there. You do not need to run it as administrator.
  2. Paste this, all five lines at once, then press Enter. 
    cd ~\Downloads
Invoke-WebRequest -Uri https://sistergroup.github.io/install-brain/brain-windows.zip -OutFile brain-windows.zip
Expand-Archive .\brain-windows.zip -DestinationPath .\brain-installer -Force
Get-ChildItem .\brain-installer -Recurse | Unblock-File
powershell -ExecutionPolicy Bypass -File .\brain-installer\install.ps1

    The fourth line clears the downloaded-from-the-internet flag that Windows puts on new files, which otherwise stops the installer loading part of itself. The fifth allows this one script to run without changing any setting on your machine.

  3. Answer four questions. Your name, your work email, your company, and where the folder should live. The recommended answer is offered for the last one, so pressing Enter is fine.

When it finishes it prints the remaining steps, which all happen inside the Claude app. The same instructions are saved in your new folder as START HERE.md.

If you would rather look first

Add -DryRun and it reports every decision it would make and changes nothing:

powershell -ExecutionPolicy Bypass -File .\brain-installer\install.ps1 -DryRun

Or Download the installer and extract it with right-click, Extract All, if you prefer not to use commands to fetch it. Do still run the Unblock-File line afterwards.

If something goes wrong

It says running scripts is disabled on this system

The -ExecutionPolicy Bypass part of the last line is what avoids that, so check it was included. It applies to that one command only and changes nothing permanently.

It cannot find part of itself, or a lib file fails to load

The Unblock-File line was skipped or did not cover everything. Run it again and then re-run the installer.

Obsidian wants administrator rights

Let it fail. The installer carries on without it and tells you at the end. Everything else still works, and Obsidian can be installed separately later. It is only there to give you a nicer way to read your notes.

I want to run it again

Safe. Every step checks first and skips what is already there. Notes, skills and your Obsidian settings are never overwritten.

The installer creates a folder of ordinary markdown files in your own storage. It reads nothing and sends nothing anywhere. The part that fills the folder in runs later, inside the Claude app, and asks your permission for each source before it reads anything.
