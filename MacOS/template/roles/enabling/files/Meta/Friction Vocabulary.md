# Friction Vocabulary

{{OWNER_NAME}}'s work is making other people's work go better, so the raw material is
other people's friction. The problem with friction is that everyone describes theirs
differently — "it's a nightmare", "it takes forever", "nobody knows where it is" — and
described differently, the same problem five people have looks like five problems.

This file fixes a small vocabulary so it stays countable. When you note friction in a
`People` note, a project or a session note, **tag it with one of these words.** Then
"three people hit *handoff* on the same report" is a finding rather than a hunch.

| Word | Means | Sounds like |
|---|---|---|
| `repetition` | The same work redone by hand each time. | "Every Monday I rebuild it." |
| `handoff` | Work stalls between two people or teams. | "I'm waiting on them, they're waiting on me." |
| `finding` | The information exists but nobody can locate it. | "It's in a thread somewhere." |
| `translation` | Moving the same content between formats or systems by hand. | "Then I paste it into the deck." |
| `permission` | Blocked on access, a licence, or someone's sign-off. | "I've asked IT." |
| `trust` | The output exists but nobody believes it. | "I check it against my own sheet." |
| `unclear` | Nobody is sure who decides, or what the answer is. | "I don't know who owns that." |
| `volume` | The work is fine, there is just too much of it. | "I can't keep up." |
| `skill` | The tool or method would work, they cannot use it yet. | "I don't know how." |

## Rules

- **Their words, then your word.** Quote how they described it, then tag it. The quote is
  what makes it real; the tag is what makes it countable. Never replace the quote with
  the tag.
- **One tag per piece of friction.** If two apply, pick the one that would have to be
  fixed first. Two tags on one thing means it is two pieces of friction — write both.
- **`unclear` is not a dustbin.** If you cannot tell which word fits, the note is too
  vague to be useful yet. Write what you actually heard and leave it untagged.
- **Friction is about work, not people.** "Slow to reply" is not friction; "approvals sit
  for a week — `handoff`" is. Nothing in a `People` note is ever a complaint about a
  colleague, and this section is not an exception to that rule.
- **Add a word if you need one**, but rarely, and add it here rather than inventing it in
  a note. A vocabulary that grows every week counts nothing. If you retire one, leave the
  row with `(retired)` so old notes still read.

## Where it goes

- `People/<Person>.md` — a `## Friction` section: what gets in their way, quoted and
  tagged.
- `Assets/<thing>.md` — a *Friction it solves* section, using the same words. This is the
  join: friction on one side, what you built on the other, the same vocabulary in both.
- The monthly review — friction that came up in several weeks belongs under *Patterns*,
  and is the strongest candidate for the next thing you build.
